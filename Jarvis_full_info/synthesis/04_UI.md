# 04 — Интерфейс (текущий UI 3.0)

## Источники дизайна в репозитории

1. `Ui интерфейс/` — исходный UI audit + HTML atlas.  
2. `Ui интерфейс Редизайн/` — **UI 3.0** (DESIGN_TOKENS, AGENT_HANDOFF, SOURCE_MAP, html/*).  
3. Реализация: `app/src/main/res/layout/*`, `DashboardActivity`, `ThemeApplier`, `ActivityFeed`, `ConversationStore`.

## Навигация (bottom nav)

`Home → Assistant → Live → Activity → More (Control Center)`

Подписи: Главная · Ассистент · Live · Активность · Ещё.

Вторичные модули под More:

`Memory · Commands/Capabilities · Automations · Companion · Models · Developer (Test Console)` + «Расширенные настройки runtime».

## Экраны / layouts (основные)

| Layout | Назначение |
|--------|------------|
| `activity_dashboard_shell.xml` | Shell: top bar, screenContainer, bottomNav |
| `screen_home.xml` | Command Deck: orb, transcript/response, activate, quick actions |
| `screen_assistant.xml` | Thread + composer + mic/send |
| `screen_live.xml` | Live session UI (ядро `liveOrb` сохранено; controls переработаны) |
| `screen_activity.xml` | Лента ActivityFeed |
| `screen_control_center.xml` | Ещё: tiles + persona/theme/toggles |
| `screen_automations.xml` | Routines UI |
| `screen_memory.xml` | Память фактов |
| `screen_skills.xml` | Команды / capabilities |
| `screen_settings.xml` | Расширенные настройки (+ include companion/models panels) |
| `screen_companion_panel.xml` / `screen_models_panel.xml` | Панели |
| `activity_onboarding.xml` / `activity_usage_guide.xml` | Онбординг / гид |
| `activity_test_console.xml` | Developer console |

## Ключевые view IDs (контракт)

Home (нельзя ломать): `homeOrb`, `activateAssistant`, `currentTranscript`, `currentResponse`.

Live (рабочие): `liveOrb`, `liveActivate`, `liveStop`, `liveMinimize`, `liveMic`, `liveCam`, `liveScreen`, `liveCaps`, `liveTranscript`, `liveTranscriptSaid`, `liveTimer`, …

## Тема (`ThemeApplier`)

Темы prefs: `CLASSIC` | `ARC` | `STEALTH` | `LIGHT`.

Применяются к window/status/nav bars и дереву views (remap цветов + recreate). Акцент орба через `CoreTheme.forState(state, accent)`.

## Персона / профиль ответа (UI)

- Персона: Classic / Friendly / Minimal (+ Developer в advanced).  
- Chat profile: Быстро / Баланс / Качество → `FAST` / `BALANCED` / `QUALITY`.  
- Toggles: Adaptive Listening, Low Power, Confirm sensitive.

## Activity / Assistant runtime stores

- `ActivityFeed` — in-process лента из событий Dashboard.  
- `ConversationStore` — пузыри диалога Ассистента.

## Визуальные токены (редизайн)

См. `copies/Ui интерфейс Редизайн/DESIGN_TOKENS.md` и `assets/jarvis-ui.css`.  
Цвета в Android: `res/values/colors.xml` (`jarvis_bg`, `jarvis_primary`, `jarvis_cyan`, …).

## Честные partials

- Live CAM / Screen share: UI есть, backend Vision/capture **не** заявлен как готовый.  
- Automations: RoutineStore in-memory (не persistent backend).

## Non-negotiables (AGENT_HANDOFF)

- Не второй mic owner.  
- Сохранять VoiceController start/speak/stop.  
- Не выдавать UI-only state за готовый backend capability.
