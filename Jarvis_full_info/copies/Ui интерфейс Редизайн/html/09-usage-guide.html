FIRST RUN // 2 MINUTES
Как пользоваться JARVIS

Модель проста: скажи → JARVIS покажет план → действие выполнится или попросит подтверждение.

01 · speak
Скажи задачу обычными словами

«Открой Telegram», «Запомни, что…», «Что у меня сегодня?» — не требуется учить специальный синтаксис.

02 · see
Посмотри intent и action plan

Новый Assistant и Activity экран делают обработку наблюдаемой: intent → tool → result.

03 · trust
Подтверждай чувствительные шаги

Отправка сообщений, системные изменения и другие risky actions отделены от обычных ответов.

04 · tune
Настрой runtime под себя

Модели, ASR/TTS, wake word, память, Companion и тема живут в Control Center.
