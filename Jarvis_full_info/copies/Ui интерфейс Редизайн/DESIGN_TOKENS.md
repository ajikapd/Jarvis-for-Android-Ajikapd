# DESIGN TOKENS — JARVIS UI 3.0

## Visual direction
Cinematic tech / superhero laboratory aesthetic: deep graphite + navy base, reactor cyan for system state, gold for primary action, restrained red for danger. No franchise marks or copyrighted artwork.

## Information hierarchy
1. Current AI state
2. User intent / context
3. Action plan / next step
4. Confirmation / destructive control
5. Diagnostics

## Core palette
- BG `#03060B`
- Panel `rgba(10,19,31,.92)`
- Cyan `#62E9F4`
- Gold `#F3BB58`
- Red `#F05D52`
- Green `#61D89D`
- Text `#F7F8FB`
- Muted `#8F9BAE`

## UX rules
- One obvious primary action per screen.
- Voice, chat and activity share one action contract.
- Secondary capabilities are discoverable but do not crowd the main bottom nav.
- Partial / stub capabilities are labelled visibly.
- Diagnostics are secondary and separated from user-facing controls.
