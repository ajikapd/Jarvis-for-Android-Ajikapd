Как пользоваться JARVIS

Короткий гид после первого запуска. Можно открыть снова из ЕЩЁ → Основные.

1 · ЗАПУСК

На вкладке ГЛАВНАЯ нажми «Активировать JARVIS». Дождись статуса ГОТОВ. Скажи: «джарвис, …».

2 · МОДЕЛИ

ЕЩЁ → Модели — скачай TTS / ASR / LLM при необходимости.

3 · КОМАНДЫ

Вкладка КОМАНДЫ — примеры фраз.

4 · LIVE

Непрерывный диалог без wake (если включён live mode).
